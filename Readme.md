# 🍴 Smart Canteen Ordering System

A simple online canteen ordering system built using:

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features

- Food menu
- Add to cart
- Remove from cart
- Automatic price calculation
- Customer details
- Place orders
- MySQL database
- Order history
- Responsive design

## Requirements

- XAMPP
- Apache
- MySQL
- Web browser

## Installation

1. Install XAMPP.

2. Copy the project folder into:

   C:\xampp\htdocs\

3. Start Apache and MySQL from XAMPP.

4. Open phpMyAdmin.

5. Create/import:

   database/smart_canteen.sql

6. Open:

   http://localhost/smart-canteen/

## Technologies

Frontend:
HTML, CSS, JavaScript

Backend:
